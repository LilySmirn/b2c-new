Интеграция

API или готовый модуль?

Выберите подходящий способ интеграции.

API

Для команд, которые хотят получить структурированные данные EasyMed и собрать собственный интерфейс и сценарии.

Готовые модули

Каждый модуль встраивается отдельно: рекомендации, EasyMed AI или проверка взаимодействий. Все три вместе — надстройка «Помощник врача» в карточке приёма.

В обоих случаях основа — структурированные данные EasyMed. API отдаёт их системе. Помощник врача показывает их на приёме и возвращает выбор в дневник.
