# API-meds

Контракт одного мок-эндпоинта: по списку названий вернуть препараты, разложенные по МНН, и зарезервированное поле взаимодействий.

Эндпоинт ещё не реализован. Адрес ниже — заглушка. Форма ответа зафиксирована так, чтобы клиент мог опираться на неё до появления сервера. Позиции в `items` повторяют поля записи из `meds/med-mag.json`.

## Эндпоинт

```
POST https://apimock.com/meds/resolve
```

`Content-Type: application/json`

Тело запроса — JSON-массив строк. Каждый элемент — название лекарства: стандартное МНН, название группы АТХ или другое название лекарства.

```json
[
  "ТЕСТОСТЕРОН",
  "Фактор свертывания крови VIII",
  "Ромашка"
]
```

Пустой массив допустим. Ответ на него — `{ "drugs": [], "interactions": null }`.

## Ответ

`200 OK`, `Content-Type: application/json`.

Один объект с двумя свойствами:

| Свойство | Тип | Смысл |
|---|---|---|
| `drugs` | массив объектов | По одному объекту на каждую строку запроса, в том же порядке и в том же количестве |
| `interactions` | `null` | Зарезервировано. Сейчас всегда `null`, взаимодействия не считаются |

Объект в `drugs`:

| Свойство | Тип | Смысл |
|---|---|---|
| `name` | строка | Та строка, которая пришла в запросе, без изменений |
| `type` | `"drug"` \| `"group"` \| `"other"` | Какое это лекарство: стандартное МНН, группа АТХ или другое название |
| `data` | массив объектов | Состав. Одна запись для МНН и для `other`, несколько записей для группы АТХ |

Объект в `data`:

| Свойство | Тип | Смысл |
|---|---|---|
| `name` | строка | Для `drug` и для элемента группы — МНН этой порции. Для `other` — то же название лекарства, что пришло в запросе |
| `items` | массив объектов | Строки каталога для этого МНН |

Объект в `items`. Имена свойств ответа и поля `meds/med-mag.json`, из которых они берутся:

| Свойство ответа | Поле в `med-mag.json` | Смысл |
|---|---|---|
| `standard_MNN` | `STANDARD_INN` | Стандартизованное МНН |
| `SMNN_code` | `SMNN_CODE` | Код узла СМНН |
| `standard_form` | `STANDARD_FORM` | Стандартизованная лекарственная форма |
| `standard_dose` | `STANDARD_DOZE` | Стандартизованная доза |
| `name_trade` | `NAME_TRADE` | Торговое наименование |
| `code_ATC` | `CODE_ATC` | Код АТХ |
| `name_unit` | `NAME_UNIT` | Единица измерения |

Поле `ACTUAL` из `med-mag.json` в `items` не входит.

## Как выбирается `type`

Каждая строка запроса проверяется по двум спискам: стандартные МНН и названия групп АТХ. Название группы АТХ — это `name_atc` / `NAME_ATC` каталога (например, «Фактор свертывания крови VIII»). Стандартное МНН — это `STANDARD_INN` из `med-mag.json`.

Порядок такой:

1. Строка есть в списке стандартных МНН → `type` равен `"drug"`.
2. Строка есть среди названий групп АТХ → `type` равен `"group"`.
3. Это другое название лекарства: не группа АТХ и не стандартное МНН → `type` равен `"other"`. Имя в ответе остаётся тем, которое передали в запрос.

МНН проверяется раньше группы. Одинаковая строка может быть и МНН, и названием узла АТХ (так устроены многие названия пятого уровня). Такая строка всегда даёт `"drug"` и один объект в `data`.

### `drug`

`data` содержит ровно один объект.

- `drugs[].name` — присланное МНН.
- `data[0].name` — то же МНН.
- `data[0].items` — все записи `med-mag.json` с этим `STANDARD_INN`. Одна запись каталога даёт один объект `items`.

### `group`

`data` содержит по одному объекту на каждое стандартное МНН, которое входит в эту группу АТХ.

- `drugs[].name` — присланное название группы.
- `data[].name` — МНН препарата внутри группы, а не название группы.
- `data[].items` — записи `med-mag.json` этого МНН, с тем же составом полей, что и у `"drug"`.

### `other`

`other` — это тоже лекарство. Так помечается название, которое не является группой АТХ и не является стандартным МНН. В ответе оно сохраняется как было передано в запрос.

Пример: в запрос пришла «Ромашка». Это не группа и не стандартное МНН, но это название лекарства. В ответе `type` равен `"other"`, а `name` равен `"Ромашка"`.

`data` содержит ровно один объект.

- `drugs[].name` — название лекарства из запроса, без замены и без пометки, что его «нет».
- `data[0].name` — то же название.
- `data[0].items` — один объект. Заполнено только `standard_MNN`, тем же названием. Остальные поля — пустые строки.

```json
{
  "standard_MNN": "Ромашка",
  "SMNN_code": "",
  "standard_form": "",
  "standard_dose": "",
  "name_trade": "",
  "code_ATC": "",
  "name_unit": ""
}
```

## Ошибки

Лекарство с `type` равным `"other"` — обычный успешный результат с кодом `200`. В этом объекте лежит переданное название.

`400 Bad Request` — тело не JSON-массив, либо элемент массива не строка. Тело ошибки:

```json
{
  "error": "Request body must be a JSON array of strings"
}
```
