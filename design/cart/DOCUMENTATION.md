# Назначения EasyMed (Препараты + вкладки)

## Что это за экран

Полный клон страницы назначений EasyMed (`klinrec.ru/cart`) для сценария **K26: Язвенная болезнь**:

- шапка 85px как на klinrec.ru (логотип, диагноз, «Рубрикатор», «Вернуться к поиску»);
- вкладки-сегмент 8 колонок идентично EasyMed; блок диагностики (и classic-вкладки) — те же строки, бейджи, чекбоксы; в конце строки — «i» и комментарий-pill (скругление 26px, как на klinrec);
- шрифты Arial и размеры названий/полей из диагностики применены и к вкладке «Препараты»;
- корзина справа: группы «Диагностика / Лечение / Шкалы и опросники / Прочее»; «+ Добавить услугу/медикамент» — модалка с типом **Медикамент** (поиск МНН/торгового из `trades.json` → строка в списке препаратов слева с меткой «сверх КР», в корзине «Лечение», заполнение дозы/формы/схемы/курса как у остальных, участие во взаимодействиях) или **Услуга** (свободный текст → «Прочее»); зелёная панель «Запись в карту / Скопировать выбранное»;
- вкладка **«Препараты»** — модернизированный блок (торговые имена, доза/форма, схема/курс, взаимодействия); в конце каждой строки — «i» + pill «Комментарий...».
- столбцы «критерий качества» и «уровень достоверности» всегда на своих местах: если значения нет, клетка пустая, название не сдвигается.
- «Доза» в строке — текстовое поле: можно вписать свою; если в базе есть варианты (250 мг, 500 мг…), справа ▾ открывает список.
- «Форма», «Схема», «Курс» — текстовые поля; двойной клик открывает карточку назначения с фокусом на поле.
- Кнопка «i» и клик по pill «Комментарий...» открывают рабочую карточку назначения (фокус на комментарии); слева назначение, справа справка. В карточке **Доза** и **Форма** — единое поле (ввод + ▾ со списком из базы), как доза в строке списка; отдельного «ниже своё» нет.
- Панель взаимодействий внизу: заголовок со счётчиком `(N)`, листание `‹ N из M ›`, клик по имени препарата в паре, блок «Замена» только если есть альтернатива в данных. Выбранные строки с взаимодействием подсвечиваются зелёным / жёлтым / красным (без значков ✓ / ! в строке).
- В карточке «i» переключатель «В корзину» стабильно меняет выбор.
- строки `kind: "scheme"` — метка «Схема · 3 препарата»; клик открывает модалку: три слота, МНН → торговое, итог «Готово». Клик по слоту 1/2/3 меняет только этот компонент, остальные остаются. «К началу» на итоге сбрасывает все три.
- строки `kind: "combo"` — метка «Комбинация · 3 ДВ»; клик открывает модалку: состав набора → торговое, итог «Готово». Клик по слоту открывает смену торгового имени того же набора; «К началу» на итоге сбрасывает набор целиком.

Отключённые в исходнике вкладки (образ жизни, вакцинация, приложение А3) показаны, но недоступны.

## Данные снаружи

### Каталог препаратов

JSON в `#preparaty-catalog` или `mountPreparaty(элемент, { catalog })`.

Поля: `diagnosis`, `tabs`, `items` (только медикаменты для вкладки «Препараты»).

Типы строк препаратов (`kind`): `trade`, `alternatives`, `scheme`, `combo`, `plain`.

### Остальные вкладки

`data/shell-tabs.json` — группы и строки диагностики / лечения / шкал (как на сайте).

### Базы из `secret`

- `data/trades.json` — торговые имена / дозы / формы  
- `data/interactions.json` — взаимодействия  
- `data/shell-tabs.json` — вкладки диагностики / лечения / шкал  

Превью подгружает их по HTTP. Запасной вариант — `data-boot.js` (и при необходимости скрипты `#preparaty-trades` / `#preparaty-interactions` / `#preparaty-shell-tabs`), чтобы торговые имена и ▾ дозы работали даже при открытии файла без сервера.

## Действия наружу

Событие `preparaty:action`:

| type | Когда |
|---|---|
| `switch-tab` | Смена вкладки |
| `select-all` | «Выбрать всю обязательную диагностику» |
| `toggle` | Кнопка выбора строки; можно отметить несколько препаратов, защита от двойного срабатывания |
| `open-name` / `pick-alternative` / `pick-trade` | Меню названия препарата |
| `open-scheme-wizard` / `close-scheme-wizard` / `pick-scheme-inn` / `pick-scheme-trade` / `scheme-complete` | Модалка настройки схемы (три компонента) |
| `open-combo-wizard` / `close-combo-wizard` / `pick-combo-kit` / `pick-combo-trade` / `combo-complete` | Модалка настройки комбинации (один набор · 3 ДВ) |
| `open-dose` / `pick-dose` / `open-form` / `pick-form` | Доза и форма |
| `open-hint` / `open-info` / `close-info` / `open-comment` | Подсказки и карточка назначения по «i» |
| `edit-intake` / `edit-intake-relation` / `info-recommend` / `info-reset` | Приём (утро/день/вечер/ночь), подстановка из КР, сброс в карточке |
| `edit-dose` / `edit-form` / `edit-scheme` / `edit-course` / `edit-comment` | Правка дозы, формы, схемы, курса и комментария |
| `check-interactions` / `replace-alternative` / `ix-prev` / `ix-next` / `ix-focus` / `ix-focus-both` | Панель взаимодействий: счётчик, листание пар, переход к строкам |
| `cart-remove` / `cart-clear` / `cart-write` / `cart-copy` | Корзина |
| `cart-template` / `cart-save-template` | Заглушки шаблонов под основной проект |
| `cart-add` / `cart-edit` / `cart-modal-close` / `cart-modal-kind` / `cart-custom-add` / `cart-custom-save` / `cart-extra-add` / `cart-extra-save` | Модалка: услуга или медикамент сверх КР |
