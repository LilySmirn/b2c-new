# Промпт: идентичная копия корзины EasyMed (klinrec.ru)

Сделай правую «Корзину назначений» в экране `preparaty` **визуально и по поведению идентичной** SideCart на `https://klinrec.ru/cart` (K26).

## Структура (сверху вниз)

1. Заголовок `Корзина назначений (N)` + кнопка очистки (иконка корзины).
2. Сегмент шаблонов: `Выбрать шаблон` | `Сохранить как шаблон` (серый блок 36px).
3. Список назначений с **группами**:
   - `Диагностика (n)` — вкладки диагностики;
   - `Лечение (n)` — вкладка «Лечение» и все препараты;
   - `Шкалы и опросники (n)`;
   - `Прочее (n)` — свои услуги/медикаменты.
4. Строка: только название (+ серый комментарий под ним, если есть); справа `×`; у своих пунктов ещё `✎`.
5. Чередование фона строк `#fff` / `#f8f9fa`. Заголовок группы — полоса `#f6f6f6`.
6. Синяя ссылка `+ Добавить услугу/медикамент`.
7. Textarea рекомендации без внешнего label (placeholder как на сайте).
8. Зелёная панель `#178e43` высотой 60px: `Запись / в карту` | `Скопировать / выбранное` с иконками.

## Модалка добавления/редактирования

- Название* (до 160), комментарий (до 500), счётчики, Отмена / Добавить|Сохранить.
- Overlay затемнение, карточка по центру.

## Не класть в корзину

Кнопку «Проверка взаимодействий» оставить в основной колонке, не в SideCart.

## Ограничения репозитория

Только HTML/CSS/JS экрана `preparaty`, без React/TS/npm. Обновить DOCUMENTATION.md.
