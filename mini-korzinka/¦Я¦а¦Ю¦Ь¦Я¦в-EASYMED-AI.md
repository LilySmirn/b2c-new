# Промпт: вкладка EasyMed AI — чат врача с ИИ

Сделай содержимое раздела **EasyMed AI** в свёрнутой мини-панели экрана `mini-korzinka`.

Верхняя навигация уже есть (`data-nav`: `clinical-recs` / `easymed-ai` / `interactions`). При **EasyMed AI** показывать чат вместо справочника КР.

## Переключение

- `clinical-recs` — поиск МКБ + вкладки + список.
- `easymed-ai` — чат врача с ИИ.
- `interactions` — короткая заглушка.
- Шапка и футер мини-панели не трогать.

## Эталон

Приветствие ИИ + чипы быстрых вопросов; ответы с нумерованными пунктами и строками услуг с **+ Добавить**. Реальный ИИ не подключать — демо в `state`. События: `ai-send`, `ai-add`.

## Ограничения

Только HTML/CSS/JS экрана `mini-korzinka`, без React/TS/npm. Обновить DOCUMENTATION.md. Открыть `preview.html`.
