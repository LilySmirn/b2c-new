# Промпт: шапка, вкладки и блок диагностики как на klinrec.ru

Скопировать с `https://klinrec.ru/cart` в экран `preparaty` **идентично** (размеры, стили, шрифты).

## 1. Шапка сайта

- Высота **85px**, фон `#0085ff`, фиксирована сверху на всю ширину.
- Контейнер max-width 1600px, отступы как на сайте.
- Слева логотип (белый, ~101×43).
- По центру/слева диагноз: Arial **700 16px**, белый, до 2 строк.
- Справа кнопки-ссылки: «Рубрикатор» (с орлом) и «Вернуться к поиску» (с лупой) — рамка белая ~88% opacity, radius 5–7px, padding ~11×18, font 14px.
- Контент страницы с `padding-top: 108px`, чтобы не уезжал под шапку.

## 2. Панель вкладок

- Сетка **8 колонок** на всю ширину чеклиста.
- Рамка `#e8ebf0`, radius 8px, высота ~40–45px, лёгкая тень.
- Вкладка: Arial **600 12px / 1.2**, до 2 строк, центр.
- Активная: цвет `#0085ff` + нижняя полоска 3px синяя.
- Disabled: цвет `#c4c9d4`, cursor not-allowed.
- Разделители между вкладками.

## 3. Блок «Диагностика обязательная» (и остальные classic-вкладки)

Строки как PrescriptionChecklist:

- Секция: фон `#f6f7f9`, font **700 13px/17px**, padding 7×12; с чекбоксом «выбрать всё» или без (padding-left 39px).
- Строка: grid `116px minmax(0,1fr) 42px 241px`, min-height 35px, border-bottom `#e0e3e7`.
- Первая колонка: чекбокс 18×18 (синий при выборе + ✓), бейджи КК / уровень 34×20.
- Название: **400 13px/1.25** Arial, цвет `#10253f`.
- Кнопка `i`: 16×16 круг.
- Комментарий: pill radius 26px, font **400 11px**, placeholder серый.

## 4. Шрифты на «Препараты»

Те же Arial и базовые размеры названия/полей (13px / 11–12px для мелких), чтобы вкладка препаратов визуально совпадала с диагностикой.

## Ограничения

Только HTML/CSS/JS в `preparaty/`, без React/TS/npm. Картинки в папке экрана. Обновить DOCUMENTATION.md. После правки открыть `preview.html`.
