# Миникорзинка

## Что это за экран

Проект **миникорзинка**. База назначений EasyMed для сценария **K26: Язвенная болезнь**.

## Режим «Свернуть»

Кнопка **«Свернуть»** в синей шапке:

- **обычный** — полный чеклист слева + корзина справа; иконка очистки корзины (урна) — справа на полоске группы **Диагностика (n)** в списке корзины (появляется и исчезает вместе с полоской); в шапке корзины вкладки **Корзина (N)** / **EasyMed AI** / **Взаимодействия**; EasyMed AI — тот же чат, что в миниатюре; **Взаимодействия** — та же проверка выбранных препаратов, что на вкладке миниатюры;
- **свёрнутый** — левая колонка и обычная корзина скрыты; компактная панель **миниатюры справочника**. В Google Chrome панель уходит в **Document Picture-in-Picture** (отдельное окно поверх других вкладок и окон); без поддержки API остаётся поверх страницы как раньше;
- **в доке** — PiP закрывается, остаётся кнопка 2×2 см с логотипом EasyMed на странице; её можно перетаскивать; клик (без перетаскивания) возвращает мини-панель (и снова PiP в Chrome).

### Поиск по МКБ

Только в свёрнутом режиме, в мини-панели над вкладками: поле ввода кода МКБ + кнопка с лупой. В обычном режиме поля нет. Событие наружу: `search-mkb` с `{ query }`. Запросы к серверу / смена каталога — в основном проекте.

### Компактная панель

- фиксирована; ширина и высота как у корзины в развёрнутом режиме (~3/10 полосы, `100vh − 155px`), перетаскивание за шапку;
- шапка: логотип EasyMed + код МКБ и диагноз + три схематические кнопки окна — **свернуть** (линия → док-логотип), **развернуть** (квадрат → полный вид), **закрыть** (красный крестик → полный вид, панель и док скрыты);
- над контентом — объединённая панель из трёх кнопок (**Клинические рекомендации**, **EasyMed AI**, **Лекарственные взаимодействия**), как вкладки: выбранная — синий текст и синяя полоса снизу; событие `mini-nav` с `{ nav }`;
- **Клинические рекомендации**: поиск МКБ + вкладки + список; при клике/фокусе на поиск под ним одной строкой выезжают две панели в стиле верхних вкладок: **Первичный / Повторный / Стационар** и **Взрослый / Ребенок**; ширина поля поиска не меняется; по нажатию поиска панели скрываются. События: `mkb-filter` `{ visit, age, visitLabel, ageLabel }`, `search-mkb` `{ query, visit, age, … }`;
  - вкладки на всю ширину полоски, по 4 на страницу: 1) Диагностика обязательная / по показаниям / Лечение / **Препараты**; 2) Шкалы и опросники / Образ жизни / Вакцинация / Приложение А3. Стрелка ›/‹ переключает страницу (выезд);
  - **Препараты** — компактные строки: чекбокс, КК, уровень, наименование, «i», комментарий (без дозы/формы/схемы/курса);
- **EasyMed AI**: чат врача с ИИ (демо без сервера) — приветствие, быстрые вопросы-чипы, нумерованные подсказки, карточки исследований с **+ Добавить** (услуга уходит в корзину как пункт «Прочее»); события `ai-send` `{ text }`, `ai-add` `{ id, name, group, cartItemId }`; история в `state.aiMessages`;
- **Лекарственные взаимодействия**: сразу проверка **уже выбранных** препаратов из «Клинические рекомендации» → «Препараты» (и в свёрнутом, и в развёрнутом режиме — в развёрнутом та же логика в нижней панели); карточки **Нельзя** / **С осторожностью**. Поиск — необязательный доп. препарат против текущего выбора. События: `ix-search` `{ query }`, `ix-check` `{ mode, resultsCount, selectedCount? }`;
- внизу панели: кнопка **«Добавить услугу/медикамент»** и поле общей рекомендации врача; запись в карту / копировать.

Флаги: `state.collapsed`, `state.minimized`, `state.miniNav`, `state.cartView`, `state.mkbSearchOpen`, `state.mkbVisit`, `state.mkbAge`, `state.aiMessages`, `state.aiAdded`, `state.miniIxMode`, `state.miniIxPairs`. События: `collapse` / `expand` / `minimize` / `restore-mini` / `close` / `mini-nav` / `cart-view` / `mkb-filter` / `ai-send` / `ai-add` / `ix-search` / `ix-check` и остальные как в базе.

## Данные снаружи

`#preparaty-catalog`, `#preparaty-shell-tabs`, `#preparaty-trades`, `#preparaty-interactions` (встроены в превью для открытия по `file://`), иначе `data/shell-tabs.json`, `data/trades.json`, `data/interactions.json`. Без встроенного JSON или локального http-сервера Chrome блокирует `fetch` — тогда у препаратов `kind: trade` не открывается список торговых имён.
